# Creative Ad Director

[English](README.md)

**v2.5.1：按场景生成视频，开启人物对白，禁止背景音乐，分镜视频与导出默认 16:9、720p。** 保留参考片节奏、四方向创意、原生选定、完整剧本和节点间自动制作流程。

同一场景 **≤30 秒（含 30 秒）**，在工具支持时一次直接生成，内部可包含多个分镜；同一场景 **>30 秒**，先出基础段，再逐段绑定紧邻的上一段真实视频，提示词写明 **“续写这个@视频”**，按已确认镜头生产总表续写后续内容。不同场景各自重新生成，不使用跨场景续写。实际模型限制在提交前检查；不支持的路线通过原生 Question 解决，不静默替换。

所有基础段与续写段均保留对白/旁白及必要环境音、音效；提示词明确禁止背景音乐、配乐和音乐性短音效，后期也不自动添加。不能通过关闭整个音轨来去掉音乐。

## 参考片节奏

新增[参考节奏规范](skills/creative-ad-director/references/reference-rhythm.md)，按用户提供的 51.1 秒视频记录画面观察与大致时间段。前段用短特写和较长全貌镜头揭幕；中段每组笑点走“触发—动作—结果”，保留反应停顿；结尾用较长镜头收束情感。

Rhythm Map 节奏表贯穿剧本、镜头总表、生成提示词和剪辑验收，明确短插镜、揭示时刻、结果停留、标题出入与切点。生成片段较长时，在编辑器裁出需要的短镜头；总时长和画幅仍按具体项目确定。

本次已检查视频元数据、全片逐秒画面、场景变化候选帧和片头转场加密采样。仅确认音轨存在，未听辨核实音乐、台词、BPM 或音画卡点，规范中明确区分已观察信息与建议音效。原视频和抽帧均不上传仓库。静态检查不等于 Lumina 成片节奏实测。

## 正确流程

1. **四个创意 → 原生 Question 选定 → 完整剧本 → 原生确认。** 四个方案在剧情前提、人物关系、冲突、笑点、产品作用和结尾上拉开差异，同时保留用户想法与事实约束。只有用户明确要求直接执行既定剧本时才跳过创意选择；仅提供想法或剧本、要求自动执行不构成跳过授权。时长由自然语速、动作、反应和剧情节奏决定；明确指定的时长作为约束。
2. **角色/道具图 → 原生确认。** 每个出镜角色生成横向 **16:9 正面、侧面、背面三视图**。最终影片的画幅单独设置。
3. **角色音色原生选项 → 真实试音。** 每个发声角色和独立旁白分别提供具体音色选项，选择后自动生成约 **20 秒**的干声试听。
4. **试听原生确认 → 正式台词。** 批准后按锁定声线生成剧本原文台词，并测量实际时长。
5. **镜头生产总表 → 原生确认。** 包含剧本行号、板图、真实语音时长、动作余量、累计时间轴、画面与机位、准确台词、图像/声线/音频绑定、前序依赖、任务状态和验收记录。
6. **自动生成、跟踪、修复分镜 → 原生分镜确认。** 每镜只绑定实际涉及的角色图与对应声线音频；同场续写等待真实前序视频，新场景清除跨场续写关系。
7. **原生后期方式选择 → 自动剪辑 → 原生成片确认。** 使用实际 Video Editor，保留人声/音效，按选择添加字幕并混音，不添加背景音乐。
8. **确认导出 → 检查真实可播放、可下载的成片。** 不把排队任务或编辑器截图当成完成交付。

所有确认、修改、重听/重看和自定义要求都走真实原生 Question 控件。需要修改时在卡片内选择具体对象和修改项，不转回普通聊天输入框。重听/重看复用素材，不重复生成。每次批准只对已展示的对应版本有效。

## 针对已报告的两种报错

用户实际返回的 Seedance 2.5 r2v 错误要求：

- 单个输入音频 **至少 1.8 秒**。
- 同一次请求的全部输入音频 **合计不超过 30.2 秒**。

制作时留出余量：单条至少 **2.0 秒**，总量控制在 **30.0 秒以内**，以处理后真实文件的测量值为准。

约 20 秒试听用于用户判断声线；分镜输入则从已批准试听中截取自然、干净的短语音参考。不能把两个 20 秒试听直接一起塞进请求，也不能把项目所有角色音频无差别绑定到每个镜头。若同时绑定声线参考和正式台词，两类音频都计入总量。旁白若在剪辑轨道处理，须在总表中明确其路线。

Agent 按 [音频预检规则](skills/creative-ad-director/references/r2v-audio.md)，使用真实原生媒体元数据检查逐条/合计时长、角色覆盖、重复附件及源声线批准状态，无需 Python、终端或用户运行命令。`scripts/validate_r2v_audio.py` 仅保留在 GitHub 源码中用于开发回归验证，不进入 Lumina 安装包。400 参数错误必须先改素材/参数再重试，禁止原样反复提交。

## 自动推进与能力边界

Agent 保存当前阶段、资产版本、Question ID、任务 ID、输入绑定和下一步动作。真实回答或任务完成后立即推进下一步；先查询状态再处理超时，避免重复付费任务。只修失败范围及其依赖，保留已批准成果。

用户确认等待是必要交互，不是流程故障。Skill 不能替用户点确认，也不能通过超时推断批准。完整执行依赖宿主真实的 Question、生成、时长测量、任务等待/恢复、剪辑和导出能力。若宿主处于 Manual mode，需要使用其支持的自动执行模式；Skill 无法越过宿主模式或自行提供缺失的回调。

产品静物图不能证明开盖、膏体、出液、真实质地/颜色或功效。白模只用于几何与构图。每段分镜视频、续写视频与最终影片默认 16:9、720p（1280×720）；角色三视图固定为 16:9；具体生成模型和时长上限运行时核验。七类剧情机制用于四方向创意探索。

## 导入与验证

下载 [creative-ad-director-v2.5.1.zip](dist/creative-ad-director-v2.5.1.zip)，替换旧导入版本，导入 `SKILL.md`、`agents/`、`references/`。安装包仅包含受支持的 `.md` 和 `.yaml` 文件；全部 Python 脚本与测试只保留在仓库。请勿把仓库源码目录直接当作 Skill 安装包上传。打包器会检查文件扩展名白名单、小写扩展名，以及最多 64 字符的英文字母/数字/下划线/连字符名称。

```bash
python3 /path/to/skill-creator/scripts/quick_validate.py skills/creative-ad-director
python3 skills/creative-ad-director/scripts/preflight.py
python3 -m unittest discover -s tests -v
python3 skills/creative-ad-director/scripts/build_skill.py \
  --output dist/creative-ad-director-v2.5.1.zip
```

测试覆盖两种已报告的音频时长失败、边界值、重复音频、声线参考与正式台词总量、缺失角色、无效/未测量时长和未批准声线。静态测试不等于 Lumina 端到端运行；原生卡片、实际声线绑定、付费生成、恢复执行和导出仍需真实环境验证。
