# Creative Ad Director

[English](README.md)

面向 Lumina 画布的搞笑剧情营销视频 Skill。此版 **2.3.0** 按用户提供的设计表重构：先展示四个差异明显的创意，再将选中方向编译为连续时间戳分镜；准备人物形象与独立音色，记录素材状态与真实绑定，生成后逐镜复核，只返工失败范围。

## 适用场景（3 个）

1. 产品发布与效果广告。
2. TikTok / 抖音短剧广告。
3. 15–60 秒社媒营销创意。

不适用：严格复刻受保护 IP、真人肖像或已有爆款人设；只有静物图却要求精确还原开盖、出液、质地和颜色；多人复杂群像与高强度连续动作。应具体说明不匹配之处，提出原创角色、有证据的产品镜头或简化调度。

## 输入与参数

输入包括产品与可选品牌、软/硬广目标、投放渠道、目标受众、时长、画幅、分辨率，以及可选的产品/人物/场景/视频/音色参考。缺少关键信息时，一次只追问一个问题；已能从材料确认的信息不重复问。

| 参数 | 设置 |
|---|---|
| 版本 | Seedance 2.5 默认；2.0 为旧产线兼容模式 |
| 时长 | 15 / 30 / 45 / 60 秒，默认 15 秒 |
| 画幅 | 默认 9:16 |
| 分辨率 | 默认 1080p |
| 广告方式 | 软广 / 硬广；搞笑剧情需求默认软广，可修改 |
| 创意 | 视觉风格、7 类剧情模式、是否参考热点结构（默认关闭） |

七类剧情采用仓库已有的喜剧机制：误会升级、预期反转、一本正经的荒诞、痛点拟人、失败补救、伏笔回扣、地位反转。截图只要求七类，未给出具体名称；这里是实现选择，不冒充原 Skill 的完整分类。

## 模型路线

- **2.5：** 4–30 秒原生直出，30 秒内使用连续时间戳；45/60 秒从已就绪视频末尾原生向后延长。延长请求必须绑定真实源视频，保持人物、产品、空间和声音连续。
- **2.0：** 单段不超过 15 秒，明确段间状态交接。

这些是用户指定的制作规则，并非已核实的供应商能力声明。运行时必须检查真实模型、接口、时长、参考素材端口、延长语义与分辨率；不支持时明确提示并给出可选替代方案，不能悄悄换模型，也不能把拼接说成原生延长。

## 制作流程

1. 建立商品证据表与创意简报，区分事实、推断和未知。
2. 展示四个在前提、人物关系、冲突、笑点和产品作用上明显不同的创意，选择后再深入。
3. 准备产品主参考、必要白模、人物形象、场景道具，以及每个发声角色的独立音色试听。文本描述、上传中、已就绪、已批准与已绑定分别记录。
4. 先写整场戏，再编译连续时间戳分镜。保留谁对谁说、前后接话、反应、停顿与转折，不压缩成宣传口号或孤立反击。
5. 按素材首次出场顺序绑定真实图片/视频/音频句柄，记录任务与版本。仅在提示词里写素材名称不算绑定。
6. 对成片逐镜复核人物、商品、空间、声音与文字；保存检查证据，只修失败范围和实际依赖项。
7. 在可编辑时间线完成字幕、声音与 CTA，核验实际导出。四个概念不等于授权生成四条成片。

网页文字、图片 URL、alt 文本和实际像素检查是不同证据。若不能看网页图片，应导入真实素材或请求直接上传。产品用态受可见证据限制：不能从静物图虚构开盖、膏体、出液或功效；白模也不能证明真实材质、颜色和内部结构。

## 导入与使用

下载 [creative-ad-director-v2.3.0.zip](dist/creative-ad-director-v2.3.0.zip)，解压后导入 `SKILL.md`、`agents/`、`references/`。ZIP 不含仓库维护脚本和测试。此版名称从 `lumina-meme-merchant` 改为 `creative-ad-director`；替换旧版时禁用或移除旧导入副本，避免重复发现。

示例：

> 用 Creative Ad Director，把这个商品链接做成一条 30 秒、9:16、1080p 的抖音搞笑剧情软广。先给四个差异明显的创意，选定后保留自然接话关系，产品只展示参考素材能证明的使用状态。

英文使用说明（少于 1,000 字符）见 [English README](README.md#instructions-for-use-under-1000-characters)。

python3 /path/to/skill-creator/scripts/quick_validate.py skills/creative-ad-director
